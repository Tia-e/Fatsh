# mem · 页 / 本 / 棚 三层记忆

把"记忆"当成三本不同粒度的本子，按父层整理节奏冻结翻新。

```
页（小时记忆）  每小时改写这一页，可增/删/改；触发天整理 → 冻结这一页，翻开新页
本（天记忆）    天整理改写这一本；触发长期整理 → 冻旧本，换新本
棚（长期画像）  只留稳定事实（是谁、雷打不动的偏好、关系定位）
```

- 冻结的页/本**只作整理参考，不注入聊天**
- 每层保留 2 格（当前 + 上一份），更早的删除
- 触发按"上次整理时间"，全异步；整理时强制开思考（即使聊天里关了）
- 门槛：距上次整理新增对话 ≥6 条才触发；`/mem gen` 手动不受限

## 指令

```
/mem              状态（页/本/棚 条数与上限、下次时间）
/mem on|off       开关
/mem show         看会注入聊天的内容
/mem clear        清空本会话三层
/mem gen 6        手动整理最近 6 小时（0 = 全部历史）
/mem limit 100    单次整理喂多少条对话（50-250）
```

## 参数 `data/memory_config.json`

| 字段 | 默认 | 说明 |
|---|---|---|
| `max_items.hour/day/profile` | 20 / 12 / 8 | 每层上限（**上限不是目标**） |
| `inject.*` | 同上 | 注入条数上限 |
| `hour_gap_seconds` | 3600 | 页的改写间隔 |
| `day_gap_seconds` | 86400 | 本的整理间隔 |
| `profile_gap_seconds` | 259200 | 棚的整理间隔 |
| `keep_pages` | 2 | 每层保留几格 |
| `min_new_entries` | 6 | 触发门槛 |
| `hour_input_max` | 100 | 单次喂料条数（50-250） |

## 数据文件（都在 `data/`）

- `memory_store_v3.json` — 页/本/棚 本体（旧版 `buckets` 结构会自动迁移）
- `memory_buffer.json` — 最近原话缓冲（跨重启保留）
- `memory_config.json` — 上面的参数
- `mem_state.json` — 开关

## 历史来源

自动/手动整理都会从 AstrBot 会话库 `data_v4.db` 的 `conversations` 回填原话（时间戳取自消息里的 `system_reminder`），所以重启、清缓冲都不影响补历史。
