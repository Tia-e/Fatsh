# tidy · 真人口吻整理

在回复发送前做脚本级清理，让语气像真人打字，不像模板。

## 做什么

1. **断句**：中文句号 `。` → 换行；逗号/分号/顿号 → 空格
2. **去空行**、压缩多余空格
3. **拦工具残留**：模型自编的 DSML（`<｜｜DSML｜｜ invoke …`）整段丢弃，避免把"调用工具"当文本发出去
4. **去独白行**：以"让我想想…"之类开头的行丢弃
5. **条内去重**：同一回复里相似度 > 0.7 的两行只留后一版
6. **跨轮去重**：和上一轮已发内容相似 > 0.8 的丢弃
7. **碎片合并**：只把 ≤3 字的碎片（"嗯/行/草"）并入上一行——**完整短句保留**，交给 human_delay 的分段器切

## 跳过

- `/` 开头的指令回复
- 含图片/语音等非纯文本内容

## 配置 `data/tidy_config.json`

可选，缺省用内置默认值。主要控制：`leak_action`（`deflect` 装傻 / `silent` 静默）。

## 位置

`on_decorating_result`（priority 默认 0，先于 human_delay 的 -100 执行），所以**分段切分拿到的是已断好句的文本**。
