# tidy · 真人口吻整理

在回复发送前做脚本级清理，让语气像真人打字，不像模板。

## 做什么

1. **断句**：中文句号 `。` → 换行；逗号/分号 → 空格
2. **去空行**、压缩多余空格
3. **拦工具残留**：模型自编的 DSML（`<｜｜DSML｜｜ invoke …`）整段丢弃，避免把"调用工具"当文本发出去
4. **四道噪声过滤**（2.0 起）：
   - 独白行（"让我想想…"）
   - 同一条里两版内容（相似度 > 0.7 只留一版）
   - 跨轮重复（和上一轮相似 > 0.8 丢弃）
   - < 8 字的碎片行并入上一行

## 跳过

- `/` 开头的指令回复
- 含图片/语音等非纯文本内容

## 配置 `data/tidy_config.json`

可选，缺省用内置默认值。主要控制：是否去句号、最小行字数、相似度阈值。

## 位置

`on_decorating_result`（priority 默认 0，先于 human_delay 的 -100 执行），所以**分段切分拿到的是已断好句的文本**。
