# addressee · 群聊接话状态机

决定"群里这句要不要接"，避免像客服一样有问必答。

## 三态

| 状态 | 行为 | 进入方式 |
|---|---|---|
| `idle` | 每条消息按概率掷骰接话（默认 0.1） | 默认 / `talk` 或 `mute` 到期 |
| `talk` | 60 秒内都回复；接话会刷新窗口（最多 3 次） | 结构化信号（@、回复）必回；或 idle 掷中 |
| `mute` | 60 秒内不主动搭话 | 模型输出 `<不接>` |

## 结构化信号

被 @、被回复、或消息里出现 `structured_names`（默认「大肥鱼」「肥鱼」）→ **必回**，不受概率与 mute 限制。
同一个人 60 秒内最多触发 2 次，防止刷屏。

## 参数 `data/addressee_config.json`

| 字段 | 默认 | 说明 |
|---|---|---|
| `groups` | `["123456789"]` | 接管哪些群（**改成你的群号**） |
| `idle_probability` | 0.1 | 闲置时接话概率 |
| `talk_seconds` / `mute_seconds` | 60 / 60 | 状态持续时间 |
| `max_refresh` | 3 | 接话后最多刷新几次 |
| `night_silence` | `["23:00","08:00"]` | 夜间静默区间 |
| `structured_*` | — | 称呼触发与限流 |

## 数据

- `data/addressee_state.json` — 每个群的当前状态（重启保留）
- `data/last_prompt.json` — 当前提示词快照（含 `<不接>` 说明，便于排查）
